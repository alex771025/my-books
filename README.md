# Моите книги

Учебно приложение за списък с книги и проследяване кои са прочетени.

## Възможности

- Добавяне и изтриване на книги.
- Отбелязване като прочетена или непрочетена.
- Маркиране на всички книги като прочетени или непрочетени.
- Броячи на прочетените и непрочетените книги.
- Запазване на данните в localStorage.
- Оформление, което се адаптира към ширината на екрана.

## Използвани технологии

HTML, CSS и JavaScript.

## Стартиране

Отворете index.html в браузър или използвайте Live Server във VS Code.

Данните се пазят в браузъра на съответното устройство и не се
синхронизират между устройства.

## Какво упражних

Работа с масиви и обекти, функции с параметри и return,
DOM елементи, събития, localStorage и CSS Flexbox.

Проектът е разработен в процеса на обучение с помощта на AI асистент.
